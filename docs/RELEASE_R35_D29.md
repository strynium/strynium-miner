- BTC、LTC 平台抽水达到本轮预算后，及时唤醒客户任务恢复流程，缩短矿机继续计算旧任务的时间。

- 矿机协议修复集中于 BTC、LTC。矿机侧实际拒绝率和平台抽水的长期比例仍需逐币验证。
