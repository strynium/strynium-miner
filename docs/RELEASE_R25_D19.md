# STRYNIUM · 服务端 R25 / 本地加密端 D19

- **连续任务下发**：非 BTC 抽水链路按顺序处理目标、难度、extranonce 与 clean 边界，及时交付最新任务；队列设有上限。
- **抽水切回**：在客户任务实际送达确认后开始有限的在途份额宽限，同时保留总截止；重复确认不延长等待。保留整数工作量计量、既定费率和历史信用。
- **拒绝率与诊断**：提交结果纳入矿池接受/拒绝、本地拒绝、超时及转发异常，未知结果不算成功；补充抽水中断与客户任务恢复记录。
- **CKB 协议切换**：显式切换兼容配置时保留账号、目标和账本身份，隔离共享普通矿池，防止隐式修改共享抽水池。不会自动改写云端现有协议配置，也不按矿机型号限制接入。
- **版本范围**：BTC 既有任务交付分支保留。D19 为配套重构建，已有 D18 可继续使用；多本地端管理界面仍仅为预览。
