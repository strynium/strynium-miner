# STRYNIUM · 服务端 R21 / 本地加密端 D15

本次将此前补充的 BCH、LTC、ETC、ZEC、CKB、KAS、DASH 协议适配一起交付，保留 BTC 原有生产转发和抽水行为。正式产品版本为 1.0.0；R21/D15 为软件包修订号。

- BCH：补齐版本滚动协商、六参数提交、独立抽水任务与主池恢复；修复有效工作量已采集但 BCH 物理算力快照未启用的问题。
- LTC：保留 Scrypt 独立难度尺度，补充精确工作量及主池/抽水提交归属验证。
- ETC：补充明确的 eth-proxy 任务、目标、header/seed、mixDigest 语义，避免与其他变体混用。
- ZEC：补齐 ZIP-301 订阅、空 extranonce、32 字节 nonce 和目标字节序校验。
- CKB：增加显式 btcpool target 协议配置，区分父块哈希与份额目标，保留原有默认配置。
- KAS：补齐 nonce 表达、原始提交保留、规范化去重、十进制任务编号和 extranonce 更新兼容。
- DASH：替换已放弃的 KDA，补齐 X11、任务恢复顺序、币种目录与本地加密通道编号。DASH 需服务端 R21 与本地端 D15 配套使用。升级发现旧 KDA 数据时会拒绝不安全迁移，不自动删除或改成 DASH。

矿机自报账号、每连接任务与 nonce 隔离、接受/拒绝/结果未知工作量分账和精确费率计量继续保留。未提高费率、未清空历史信用；结果未知的份额不重发。低费率、矿池难度、随机出份和设备数量仍影响矿池短时曲线，不能承诺每个短窗口平滑。

本版通过的软件协议、回归和安装包检查见验证报告。未拥有全部币种的实机与矿池变体，不能将离线测试称为全部矿机兼容或 24 小时现场验收。上线后按币种逐项核对实际任务、接受份额、抽水和主池恢复。
