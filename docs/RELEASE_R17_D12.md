# 服务端 R17 / 本地加密端 D12 · 2026-10-31

本版处理旧任务提交和抽水切换时的连接生命周期。未知、过期任务返回明确拒绝，保持可继续工作的矿工连接；主池与抽水任务、账户、难度和 nonce 继续隔离。已发送但结果不明的抽水份额保留 Unresolved 和持久化记录，不当作成功，不重投。只有确认主池仍可用并可恢复的情况采用保留连接路径；持久化失败或不能确认切换仍隔离会话。

抽水切入与恢复先取得矿机会话的命令处理边界，再准备和确认任务，避免与仍在等待上游的份额互相等待。保留原费率和账本。

最终组合原生回归：**1332 通过、0 失败、11 忽略**，共 119 个测试目标，涉及 fee-module, minerproxy-runtime, minerproxy-server, proxy-core。最终全目标 Clippy（-D warnings）通过。忽略用例不计入通过；此前的红测和中间失败均保留在本地完整日志中。本报告只记录最终验收，不累加重叠定向测试数量。

Windows x64 与 Linux x64 musl 使用批准的 workspace 构建入口；隔离 HTTPS 控制台、证书与健康检查通过。三个 D12 本地加密端包直接复用 R16 发布的原始字节，无需更新本地端。

**矿场实机验收尚未完成。** 本报告不代表矿机已恢复标称算力，也不宣称持续抽水已通过。更新后先单台连续观察至少 30 分钟，核对矿机本机算力、有效/拒绝份额、HW 错误、断线重连和运行时长；这仅是初步连接观察，抽水验收还必须覆盖多个完整抽水周期。

同名并发会话或同地址的备用会话可能触发唯一身份保护并暂停抽水；本轮未改变此规则。测试不包含所有固件、所有发行版 apt 依赖解析或 SOLO 功能验收。
