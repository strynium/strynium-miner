# STRYNIUM · 服务端 R29 / 本地加密端 D23

- **CKB**：修复矿池新任务到达与矿机旧任务提交之间的交接竞态。同一会话内保留短暂在途处理窗口，继续使用原任务的目标、nonce 和归属；适用于三种已实现的 CKB 协议形式。
- **LTC / ZEC / CKB**：恢复客户任务前先处理已收到的有界请求队列，减少任务切换抢在已收到份额之前造成的本地拒绝；仍保留在途数量上限及交接屏障。
- **抽水账本**：合并队列中有序完整快照的持久化写入，保留所有审计事件；保存完成后才确认，异常时关闭写入入口。超时和存储错误分别记录，未知结果不会自动重放。
- BTC 协议串行路径、既定费率、身份和历史工作信用保持原有规则。没有清空账本或用旧测试记录代替新结果。
- 服务端 R29 与本地端 D23 均重新构建。独立多本地端管理仍为预览；矿场本地软件需另外更新。
- 本版通过软件验证后发布，**真实矿机拒绝率、实际抽水比例和长期平滑仍需更新后实测**；不宣称通过 24 小时验收。
