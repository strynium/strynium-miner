# STRYNIUM · 服务端 R23 / 本地加密端 D17

- 直连或本地加密接入的同端口、同完整矿工名的连接共用原有抽水账本，由有真实矿池接受份额的连接承担抽水。多个工作连接汇总有效工作量，抽水所有者保持唯一。
- 工作连接切换保留身份、信用及调度，等待旧任务关闭与账本持久化确认；不因重复备用连接单独暂停抽水。
- 清理长期空闲的重复连接：保留 15 分钟启动宽限、10 分钟无提交宽限、在途提交与抽水占用保护；只有另一条近期出有效份额的连接仍在线才执行清理。
- CKB 订阅失败后尝试下一矿池地址；新增端口优先使用蚂蚁 / BTCpool 的 K7 协议。已有端口需核对所选协议与矿池地址，不会静默转换历史协议。
- LTC 抽水预备使用 Scrypt 精确难度口径，并等待实际新任务绑定；难度通知本身不产生份额或收费。
- ZEC / CKB 抽水预备按矿池实际下发并绑定到任务的目标难度计量，复用已准备连接；不能保证矿池降低难度，截止时仍以真实工作量结算。
- BTC 核心计量及费率不变，客户与抽水的账号、任务、nonce、份额归属继续隔离。本地端 D17 为配套重构建，D16 可继续使用。
- 本版通过软件回归后发布；仍需 L7、Z11、K7 现场复测，不宣称单矿机或 24 小时算力曲线无波动。
